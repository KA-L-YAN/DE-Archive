# DE Interview Prep — Aug 25 to Oct 31

Local companion to the "Professor" Claude project (Notion-backed timetable, 4 phases).
Every session's problems + corrected answers get logged here so they're searchable
and re-runnable later, without depending on the chat history.

## Structure

- `sql/dayNN-topic.sql` — one file per session. Each has: problem statement (comment),
  my attempt, the corrected/working version, and a note on what was actually wrong.
- `python/dayNN-topic.py` — same pattern for Python problems.
- `progress-log.md` — one line per day: topic, verdict (solid / shaky / gap), follow-up needed.

## How to use with SQLTools

Open a `.sql` file, select a query, run it against a connected DB (Postgres/MySQL driver
installed) via the SQLTools sidebar — or just read/edit them as a reference log even
without a live connection.
