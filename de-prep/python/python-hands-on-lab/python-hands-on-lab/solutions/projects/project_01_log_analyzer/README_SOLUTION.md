# Reference solution — project_01_log_analyzer

This folder is the complete implementation of the project described in `README.md` (identical to the starter README).
The starter in `13_real_world_projects/` was generated from this code by removing function bodies, so signatures and docstrings match exactly.

Run the tests against this solution from the lab root:

```bash
LAB_TARGET=solutions pytest tests/projects -k project_01 -v
```

Read it *after* you have a working version of your own, and compare: module boundaries, what is pure vs. what does I/O, where state is committed, and how failures are reported.
